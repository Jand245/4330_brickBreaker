# Brick Breaker

A dependency-free Flutter brick breaker starter.

## Run it

1. Open this folder in Android Studio.
2. Run `flutter create .` once to generate the Android/iOS runner folders.
3. Run `flutter pub get`.
4. Choose an emulator or connected phone and press Run.

## Controls

- Tap to launch the ball.
- Drag anywhere on the game board to move the paddle.
- Clear every brick to win.
- Tap the finished screen to restart.
